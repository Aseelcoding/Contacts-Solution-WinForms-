# Contacts Solution (WinForms)

Contacts Management System is a desktop application built using C# WinForms for managing contact information. It allows users to add, update, search, and manage contacts, including storing and displaying contact profile images.

The project is built using Three-Tier Architecture (3-Tier Architecture):

Presentation Layer: Handles the user interface using Windows Forms.
Business Logic Layer (BLL): Contains the application logic and manages operations such as contacts and countries.
Data Access Layer (DAL): Handles communication with the database and performs CRUD operations.

The main purpose of using the 3-Tier Architecture is to separate responsibilities, making the application easier to understand, maintain, modify, and extend.
